# Developer Portfolio - Aakash

A modern, responsive personal developer portfolio built for the Alfa Coding Club submission.

## Tech Stack
- **HTML5:** Semantic markup and accessible page layout
- **Tailwind CSS:** Modern utility-first styling with native dark mode support
- **Vanilla JavaScript:** Theme toggling, modal controls, and dynamic form validation

## Key Features
-  **Theme Switcher:** Dark/light mode toggle with state persistence
-  **Fully Responsive:** Smooth layout transitions across mobile, tablet, and desktop
-  **Interactive Previews:** Modal popups for project showcases
-  **Client Validation:** Custom toast notifications and instant input feedback
-  **Zero Framework Overhead:** Pure single-file architecture for fast loading
